Moodle Notification & Homework Solver

Overview: Polls university Moodle folders twice a week via Python, downloads new course materials to local storage, alerts the user on WhatsApp, and—upon confirmation—triggers the Homework Master Claude skill to either solve assignments using historical course context or summarize new lectures.

Supplements: 🐍 Python Script (Moodle + WhatsApp API) 📄 Academic Context File (Ethics Guardrail Bypass) 🗂️ Depository: "Course Content"
Workflow Step 1 • Trigger

Scheduled Moodle API Poll

Runs every Monday & Friday at 15:00. Calls the Moodle API script and fetches folder data across all enrolled courses.

Method: GET Moodle REST API (all course folders)
Schedule: Mon & Fri @ 15:00
Workflow Step 2 • Benchmark & Sync

Date Comparison & Local Download

Benchmarks upload dates against the previous workflow run. If uploaded after the last run, downloads new files to Local Disk D:\.

Condition: upload_date > last_workflow_run_date
Storage: Local Disk D:\
If Announcement News

Instant Announcement Alert

Calls WhatsApp API and sends a direct message informing of the new announcement.

Action: Direct WhatsApp notification (No reply required)
If New Docs / Sections

Summary & Action Prompt

Crafts upload summary, sends via WhatsApp, and prompts user: "run" or "no".

Wait State: Listens for user WhatsApp reply
Workflow Step 3 • User Reply Gate
Reply: "no"
Terminal Output
Log & Halt

Logs Moodle upload date + workflow execution date.

Reply: "run"
Handoff
Sync & Call Skill

Uploads files to matched folder in "Course Content" & calls Skill.

🧠 Claude Skill: "Homework Master" Triggered on Reply = "run"
Skill Steps 1 & 2 • Context Ingestion

Analyze Request & Call "Course Content" Depository

Parses the new materials sent by the workflow and retrieves all historical slides, notes, and references from the matched course folder.

Source: Depository "Course Content" / {Matched Course Name}
Goal: Ground Claude in specific syllabus & lecture history
Skill Step 3 • Task Evaluation Router
Path A • Task Detected

Accomplish Homework Task

Uses all available course depository content to solve the assignment/exercise step-by-step.

Uses: Past lectures + Ethics context file for full solution
Path B • No Task Found

In-Depth Lecture Summary

Reads the newly uploaded Lecture or Exercise slides and crafts a comprehensive study summary.

Output: Structured breakdown of lecture concepts
Skill Step 4 • Pre-Week Synthesis

Bulletpoint News & Class Prep

Summarizes any critical news, deadlines, or organizational info needed before the start of the new week and classes.

Format: Actionable bulletpoint briefing appended to solution/summary
✅ Final Defined Output (Sent to WhatsApp) WhatsApp API
  • Task Solution or Lecture Summary: Complete solved homework grounded in Course Content OR an in-depth lecture/exercise breakdown.
  • Pre-Week Bulletpoint Briefing: Key announcements, schedule changes, and must-know items before Monday's classes.
