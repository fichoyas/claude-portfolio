Find & Verify Deliverable Work Email

Overview: Generates statistically ranked candidate work email addresses from a prospect's name and company domain via Python, then sequentially probes the target mail server using the NinjaMailTester API with self-throttling and repeat-block detection to confirm real deliverability before outreach.

Supplements & Tools: 🐍 scripts/generate_formats.py 📄 references/email-formats.md 🥷 mailtester-ninja API (verify_email)
Step 1 • Parse Input & Clean Domain

Extract Name Tokens & Normalize Domain

Accepts a single prospect or bulk list. Extracts first, last, and optional middle names. Strips http(s)://, www., paths, and query params from the domain (or resolves company domain via web search).

Mode: Single lookup or sequential Bulk Mode
Input: First Name, Last Name, Cleaned Bare Domain
Step 2 • Candidate Generation Script

Run scripts/generate_formats.py

Transliterates accents/non-Latin scripts to plain ASCII, strips titles (Dr., Jr.) and punctuation, and outputs ~28–42 candidate emails ordered by statistical likelihood.

CLI: python scripts/generate_formats.py --first <f> --last <l> --domain <d>
Output: Prioritized JSON array [{"format": ..., "email": ...}]
🥷 Step 3 • Sequential Mail Server Verification Loop Throttle: ≤ 8 requests / 10s (~1.25s interval)
One-at-a-Time Probe (Never Parallel)

Call mailtester-ninja API

Queries https://happy.mailtester.ninja/ninja sequentially for each candidate in priority order and inspects the returned code and message.

Why Sequential: Prevents stream/permission errors & respects 11/10s limit
Response Fields: email, mx, code ("ok" | "mb" | "ko"), message
Response Code & Repeat-Block Router
code: "ok"

Accepted (Valid)

Deliverable address confirmed. Stop testing immediately for this person.

Action: Break loop → Report Valid
code: "mb" • Catch-All

Catch-All Domain

Domain accepts everything. Log as Catch-All candidate, but keep testing for a hard ok.

Action: Record hit → Test next format
code: "ko" / Single "mb"

Rejected Candidate

Address rejected or single transient error. Increment rejected counter and test next format.

Action: Advance to next candidate
2x Identical "mb" Error

Repeat-Block Circuit Breaker

Two consecutive SPAM Block or No Mx hits. Abort testing immediately for this person.

Status: Undeterminable (Server blocking probes)
✅ Step 4 • Final Defined Output (Chat Report) Per-Person or Bulk Grouped
  • Valid Deliverable Address: Exact email confirmed with ok / Accepted.
  • Catch-All / Undeterminable Notice: Clearly labeled unconfirmed Catch-All hits or server-block status.
  • Clean Rejection Count & Fallback: Single-line count of rejected formats (e.g., "24 other formats tested, all rejected") plus the #1 statistical convention flagged as unverified if nothing matched.
