Data Enrichment Orchestrator & Automated Lead Replacement

Overview: A modular 3-workflow n8n architecture that pulls target companies from HubSpot, searches Apollo for sustainability decision-makers using an automated keyword-retry loop (Subflow 1), enriches contact data, checks HubSpot for existing records, automatically sources net-new replacement leads whenever a prospect is already in HubSpot (Subflow 2), runs OpenAI solution matching and MailNinja email validation, and exports a clean CSV.

View Layer:
Step 1 • Trigger & Execute Sub-Workflow 1

Call SubFlow People Searching with Apollo

Triggered via When clicking 'Execute workflow'. Invokes Subflow 1 to fetch HubSpot companies and run iterative Apollo keyword searches until target sustainability contacts are found.

Step 2 • HTTP Request (Apollo API) + Edit Fields

People Enrichment (singular) → Final Fields

Enriches each discovered prospect via Apollo POST API and maps normalized contact & company attributes in Final Fields.

Endpoint: POST https://api.apollo.io/api/v1/people/match
Mapping: Extracts email, title, seniority, company domain, LinkedIn
Step 3 • Batched Loop Over Items + Rate-Limit Wait

Loop Over Items1 → Search contacts in HS

Iterates through enriched prospects, searches HubSpot CRM (search: contact), combines CRM metadata via Merge HS data, and paces requests with a Wait1 node.

Loop Cycle: Loop Over Items1 → Search HS → Merge (combine) → Wait1
Step 4 • Router: If already in HS
If True (Path A)

Call SubFlow Replacement Leads

Passes existing company context via Keep needed information1 to Subflow 2 to source a fresh replacement contact.

If True (Path B)

Format Original HS leads

Preserves and standardizes the existing HubSpot contact record alongside its CRM history.

Feeds Input 2 of Merge all contacts
If False (Net-New)

Keep needed information

Prospect is not in HubSpot. Retains clean Apollo-enriched fields directly for downstream matching.

Feeds Input 3 of Merge all contacts
Step 5 • Consolidation & OpenAI Solution Matching

Merge all contacts → Final Sort → Solution Matching

Appends all 3 streams (Replacements + Existing HS + Net-New), sorts via JS code, runs an OpenAI Agent node (Solution Matching) to map each prospect to the right product line, and combines via Merge1.

AI Node: OpenAI Response Text model with tool support
Auxiliary Loop: MailNinja GET validation loop + Parse MailNinja
✅ Final Defined Output (Mainflow) Final Output Fields → Final CSV
  • Enriched & Replaced Lead CSV: Combines net-new prospects, formatted HubSpot records, and automatically sourced replacement leads.
  • AI Solution Fit + MailNinja Verification: Appends tailored solution classification and deliverable email status.
Subflow 1 • Called at Step 1 of Mainflow
Subflow 1 • Step 1: HubSpot Company Ingestion

When Executed by Another Workflow → Get companies from HS

Fetches target company records with clean domains from HubSpot CRM (`POST /crm/v3/objects/companies/search`) and splits them into individual items via Split Out.

Prerequisite: Companies in HubSpot must have a clean domain for matching
Subflow 1 • Step 2: Primary Apollo Sustainability Search

HS/Apollo Name Matching → Apollo People search keyword sustainability

Matches the HubSpot organization to Apollo and queries people matching the primary sustainability keyword, combining results with company metadata in Merge1.

Combines original HubSpot company payload (Input 1) with Apollo candidates (Input 2)
🔄 Subflow 1 • Step 3: Iterative Keyword Retry Engine (Loop Over Items) Fallback search when primary keyword returns 0
Stop Trying? = True (Retry Path)

Apollo People Search Retry Keywords

Steps through fallback department/role keywords via Current Retry → Apollo Search → Merge Retry Json → Update until candidates are found or retry list is exhausted.

Prevents zero-lead drops on companies that use non-standard job titles
Stop Trying? = False (Complete)

Return Company → Next Item

Commits discovered contacts for the current company and advances Loop Over Items to the next account.

Exits via Split Out2 → Prepare for MainFlow
✅ Subflow 1 Output: Prepare for MainFlow

Returns flattened list of discovered Apollo prospect IDs and matched HubSpot company metadata back to Mainflow Step 2.

Subflow 2 • Called when Contact is Already in HubSpot
Subflow 2 • Step 1: Replacement Candidate Search

Apollo People search keyword sustainability → Split Out

Receives companies whose initial contact was already in HubSpot and queries Apollo for alternative decision-makers at the same organization.

Unpacks candidate array via Split Out → Edit Fields
Subflow 2 • Step 2: Dual-Stage Deduplication Gate

Remove Duplicates → Check if Apollo ID is duplicate

Deduplicates candidate records within the batch and cross-checks each Apollo ID against an n8n Data Table so previously processed leads aren't re-enriched.

Saves Apollo enrichment credits by filtering known IDs before POST match
Subflow 2 • Step 3: Enrich & Verify Replacement in HubSpot

People Enrichment (singular)1 → Loop Over Items1 (HS Check)

Enriches the replacement lead in Apollo, maps Final Fields, and runs a HubSpot contact search loop (with Wait1 rate-limit pacing) to confirm the replacement status.

Loop: Search contacts in HS → Merge HS data → Wait1
✅ Subflow 2 Output: Prepare for MainFlow

Returns verified replacement contact payload back to Input 1 of Merge all contacts in the Mainflow.
